# Leo Felix – Profile

Personal profile site, live at https://leofelixlaw.github.io/mypage/

Built with **React** and **SCSS** (Vite). Source lives in `app/`; the built site is published to the repo root, which GitHub Pages serves.

```bash
cd app
npm install
npm run dev      # local development
npm run deploy   # build and copy the site to the repo root, then commit and push
```
